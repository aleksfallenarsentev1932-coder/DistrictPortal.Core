# Отчёт ЛР10: Логирование в DistrictPortal

## Что сделано
- В проект DistrictPortal интегрирован сервис `AppLogger` для записи событий в файлы с ежедневной ротацией (папка `logs/`).
- Реализовано логирование ключевых операций:
    - ADD (добавление)
    - UPDATE (редактирование)
    - BACKUP (создание резервной копии)
    - EXPORT (экспорт данных)
    - IMPORT (импорт данных)
- В консольное меню добавлен пункт **14) Логи**, позволяющий просматривать последние 20 записей лога за текущий день.

## Где лежит лог
Логи сохраняются в директории `logs` рядом с исполняемым файлом программы. Файлы именуются по формату: `app_YYYY-MM-DD.log`.

## Как проверить
1) Запустить `DistrictPortal`.
2) Выполнить несколько действий (добавить объявление, отредактировать его).
3) Выбрать в меню пункт **14** — в консоли отобразятся последние записи лога.
4) Проверить содержимое файла в папке `logs/` — там должны быть записи с отметками времени и типом события (INFO/ERROR).
