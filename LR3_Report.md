# Отчёт ЛР3 DistrictPortal

## Что сделано

В PortalService добавлены методы:
- GetExisting(id) — вспомогательный метод поиска объявления по Id
- ChangeCategory(id, newCategory) — изменение категории объявления по Id
- Delete(id) — удаление объявления по Id

В консольном меню добавлены пункты:
- 3) Изменить категорию объявления
- 4) Удалить объявление

Добавлена проверка ввода Id и номера категории (TryParse и валидация диапазона).

## Как проверить

1) Запуск приложения (F5)
2) Добавить 2 объявления через пункт меню 1
3) Изменить категорию объявления с Id=1 через пункт меню 3
4) Удалить объявление с Id=2 через пункт меню 4 (с подтверждением 'y')
5) Проверить итоговый список через пункт меню 2
6) Проверить обработку ошибок (ввод букв 'abc' вместо Id, ввод несуществующего Id)
