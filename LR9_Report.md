# Отчёт ЛР9

## Что сделано
1. **Модель статистики**: Создан класс `TaskStats` для хранения данных (общее количество задач и счетчики по статусам).
2. **Логика подсчета**: В сервис `PortalService` добавлен метод `GetStats()`, который считает задачи по статусам.
3. **Меню**: В консольное приложение добавлены пункты:
   - 12) Статистика (вывод данных на экран).
   - 13) Экспорт отчёта (сохранение статистики в текстовый файл в папку `reports/`).

## Как проверить
1. Добавить несколько задач.
2. Выбрать пункт **12** и убедиться, что цифры соответствуют общему количеству и статусам.
3. Выбрать пункт **13** и проверить, что в папке `reports/` появился файл `report_...txt` с результатами.

## Вывод
Программа научилась анализировать данные и выгружать результаты в файл. Это позволяет быстро оценить состояние работы с задачами, не просматривая весь список целиком.
