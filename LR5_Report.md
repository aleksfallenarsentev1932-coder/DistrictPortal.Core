# Отчёт ЛР5

## Что сделано
- В модель `Post` добавлено поле `Description`.
- В `PortalService` реализован метод `UpdatePost` для изменения названия и описания по ID.
- В консольное меню `Program.cs` добавлен пункт "5) Редактировать объявление".
- Настроено автоматическое сохранение в `data/posts.json` после каждого обновления.

## Как проверить
1) Запустить программу (F5).
2) Добавить объявление (1).
3) Выбрать пункт (5), ввести ID созданного объявления.
4) Изменить заголовок и описание.
5) Выбрать (2) и убедиться, что описание отображается.
6) Перезапустить программу — данные должны остаться на месте.
