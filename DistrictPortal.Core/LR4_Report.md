# Отчёт ЛР4 — DistrictPortal

## Что сделано
- Добавлен новый проект библиотеки классов DistrictPortal.Storage
- Реализован класс JsonPortalStorage (методы Load/Save) для сериализации объявлений в файл posts.json
- Конструктор класса PortalService адаптирован для старта с загруженным списком и корректного расчёта автоинкремента Id
- В главном цикле Program.cs добавлено автосохранение данных после добавления новых объявлений
- Настроена автоматическая загрузка базы данных при запуске приложения

## Где лежит файл данных
Путь выводится в консоли при запуске: подпапка `data/posts.json` внутри папки сборки приложения.

## Как проверить
1) Запустить программу (F5)
2) Добавить 2 объявления через пункт меню 1
3) Выйти из программы (0)
4) Запустить приложение снова
5) Выбрать пункт 2 (Показать ленту объявлений) — все добавленные ранее объявления загружаются из JSON-файла и остаются на месте.
