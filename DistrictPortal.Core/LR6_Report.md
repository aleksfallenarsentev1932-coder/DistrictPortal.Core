# Отчёт ЛР6

## Что сделано
- В `PortalService` добавлены методы: `SearchByTitle(query)`, `FilterByCategory(category)`, `SortById(ascending)`.
- В консольное меню добавлены пункты: 
  - 6) Поиск по названию
  - 7) Фильтр по категориям
  - 8) Сортировка по ID
- Добавлена функция `PrintPosts` для единообразного и удобного вывода списка объявлений.
- Реализована защита от вывода пустого списка (выводится сообщение "Ничего не найдено").

## Как проверить
1) Добавить несколько объявлений с разными категориями.
2) Использовать поиск (6) по части названия (работает без учета регистра).
3) Использовать фильтр (7) по категориям (0-3) или сбросить фильтр (4).
4) Использовать сортировку (8) для изменения порядка отображения.
5) Убедиться, что при попытке найти несуществующее объявление программа корректно пишет "Ничего не найдено".
