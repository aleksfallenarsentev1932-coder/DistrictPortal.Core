# Отчёт ЛР7 — DistrictPortal

## Что сделано
- Добавлен метод `ReplaceAll` в `PortalService` для корректного импорта данных (полная замена списка с пересчетом ID).
- Создана служба `BackupService` для автоматического резервного копирования текущей базы данных.
- В `Program.cs` реализованы новые функции:
  - 9) Резервное копирование (Backup) — создает копию `posts.json` в папке `backups` с меткой времени.
  - 10) Экспорт в файл — сохраняет текущий список объявлений в отдельный JSON-файл в папке `exports`.
  - 11) Импорт из файла — позволяет загрузить данные из стороннего JSON-файла, выполнить бэкап текущих данных и произвести замену.
- Реализована обработка ошибок: программа корректно проверяет существование файлов и наличие данных, не допуская аварийного завершения (падения).

## Как проверить
1) Запустить программу (F5).
2) Добавить пару объявлений через пункт (1).
3) Выбрать пункт (9) — в папке `backups` появится новый файл.
4) Выбрать пункт (10) — в папке `exports` появится файл с текущим списком объявлений.
5) Выбрать пункт (11), ввести путь к экспортированному файлу, подтвердить импорт (y) и подтвердить замену (y).
6) Проверить ленту (2) — данные должны соответствовать импортированным.

## Вывод
В ходе работы была реализована надежная система работы с файлами, обеспечена защита данных через резервное копирование и гибкий механизм импорта/экспорта данных между файлами.
